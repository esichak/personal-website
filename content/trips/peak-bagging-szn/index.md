8 peaks in Desolation Wilderness (Echo Peak, Keiths Dome, Cracked Crag, Jacks Peak, Dicks Peak, Peak 9579, Peak 9376, Mount Tallac)

It ended up taking me close to 12 hours with only a few short breaks. There were so many sections OnX was showing as a trail when there just wasn’t. So much rock hopping and ridge scrambling. I was feeling pretty ok physically but towards the end was completely zapped mentally from having to pay attention to each footstep on loose rock. A very rad loop that I’ll need some time to forget about before doing again
